01
Capital Project System
▼
The ask “We want to have all of our capital projects information from the last five years consolidated into one place, where everyone can access, enter, and view details easily.”
Built a full-stack database system using ASP.NET and PostgreSQL that consolidated all capital project data into a single internal web application. The system allowed users to import CSV files or manually input data, with search, filtering, and detailed project views. Replaced fragmented Excel workflows entirely.
Impact: One system replaced dozens of disconnected spreadsheets
02
Compliance Dashboard
▼
The ask “We want to track our chemical output without having to manually go look it up online every day, and if you could visualize that for us.”
Automated compliance monitoring by integrating daily data from a proprietary source into Power BI. Used Python and Power Query to clean and transform data for 15 chemicals across 15 locations, building a dimensional model for analysis. The dashboard tracked compliance thresholds in real time and triggered automated reports via Power Automate, alerting the responsible manager whenever a chemical approached non-compliance.
Impact: Zero missed reporting deadlines
03
Automated Reporting
▼
The ask “We need a way to stop our compliance analysts from typing thousands of repetitive data points every single week.”
Mapped the entire data flow and used Excel as the warehouse layer. Built a template that auto-generated a master sheet, monthly sheets, and yearly sheets for each location annually. The team entered data once in the master sheet, and XLOOKUP formulas connected it to all downstream reports. Once entered, data flowed automatically into monthly and annual reports, fully removing all manual work.
Impact: Manual reporting fully automated
04
Sales Data Analysis
▼
The ask “I’ve got a bunch of data locked up in SAP. Not sure what you could do, but some insights or interesting finds would be nice.”
Pulled sales data from the SAP API (job type, cost, revenue, and margins) and stored it in Azure SQL Data Warehouse. Ran a cross-reference analysis and discovered that residential window services had the highest margins but the fewest jobs. Unlike car services where people have a “car guy,” residential window tinting is actively searched rather than referred, meaning low awareness was the bottleneck, not demand. Recommended marketing adjustments targeting search audiences to boost conversions and improve overall margins.
Impact: Identified highest-margin segment and recommended marketing pivot
